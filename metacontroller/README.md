
# MetaController Resources

This directory contains MetaController definitions and configurations for managing Nightscout instances.

## Structure

- `controllers/` - Contains CompositeController definitions
- `webhooks/` - Contains webhook implementations
- `examples/` - Example usage of the controllers

## Components

1. NightscoutInstance Controller - Manages Nightscout deployments
2. Webhook API - Integrates with existing deployment controller
